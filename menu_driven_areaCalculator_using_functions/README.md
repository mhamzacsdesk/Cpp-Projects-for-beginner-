# Geometry Area Calculator (C++)

A menu-driven command-line program written in C++ that calculates the area of various geometric shapes using userdefined functions and an interactive loop.

<br>

<b>Features</b>
<ul>
<li><b>Circle Area Calculation:</b> Calculates area using radius.</li>
<li><b>Rectangle Area Calculation:</b> Calculates area using length and width.</li>
<li><b>Triangle Area Calculation:</b> Calculates area using base and height with floating-point division.</li>
<li><b>Interactive Menu Loop:</b> Uses a `do-while` loop so the program stays open for multiple calculations.</li>
<li><b>Exit Option:</b> Safely terminates the program when the user enters `0`.</li>
</ul>

<br>

<b>C++ Concepts Applied</b>
<ul>
<li><b>User-Defined Functions:</b> Organizing logic using function prototypes and return-value functions.</li>
<li><b>Floating-Point Precision:</b> Using `double` data types and `1.0 / 2.0` floating-point arithmetic to prevent integer truncation.</li>
<li><b>Control Flow:</b> Using a `do-while` loop with conditional `if` statements for menu selection.</li>
<li><b>Standard Console I/O:</b> Using `#include <iostream>` for input and output operations.</li>
</ul>
