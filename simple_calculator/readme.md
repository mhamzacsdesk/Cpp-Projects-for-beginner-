<b>Simple Console Calculator (C++)</b>
<br>
Before practicing this calculator I hope you have little bit knowledge of 'data type', 'conditions', 'loops & switch'.

A basic command-line calculator program written in C++ that performs basic arithmetic operations using a `switch` statement.

<b>Features</b>
<ul>
<li>Standard Operations: Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).</li>
<li>Operator Selection: Uses a `switch` statement for clear and efficient branching based on user input.</li>
</ul>
<b>C++ Concepts Applied</b>
<ul>
<li>Control Flow: `switch` statements and conditional logic (`if / else`).</li>
<li>Data Types: `double` for precision floating point numbers and `char` for arithmetic operators.</li>
<li>Console I/O: Standard streams (`std::cout` and `std::cin`).</li>
<ul>
