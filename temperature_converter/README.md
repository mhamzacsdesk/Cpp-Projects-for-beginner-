<b>Temperature Converter (C++)</b>

A menu-driven command-line program written in C++ that converts temperatures between Fahrenheit and Celsius continuously until the user exits.
<br>
<b>Features</b>
<ul>
<li>Fahrenheit to Celsius Conversion: Calculates standard temperature conversions.</li>
<li>Celsius to Fahrenheit Conversion: Converts Celsius values to Fahrenheit accurately.</li>
<li>Interactive Menu Loop: Uses a `do-while` loop so the program stays open for multiple calculations.</li>
<li>Exit Option: Safely terminates the program when the user enters `0`.</li>
</ul>
<b>C++ Concepts Applied</b>
<ul>
<li>Header Inclusion: Using `#include <iostream>` for input and output operations.</li>
<li>Control Flow: `do-while` loop combined with `if` and `else if` statements.</li>
<li>Data Types: `float` for handling decimal-based temperature values.</li>
<li>Standard Console I/O: `std::cout` for formatting output and `std::cin` for capturing user input.</li>
</ul>
